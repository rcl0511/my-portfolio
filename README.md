너는 10년 차 이상의 시니어 소프트웨어 아키텍트이자 기술 전문 기획자야. 내가 개발한 **AI 기반 응급 대응 시스템 'SOSAI'**의 핵심 기술 스택과 설계 전략을 분석해줘.

이 프로젝트는 단순히 정보를 제공하는 웹을 넘어, 특허 출원과 보건의료 창업 경진대회 입상을 통해 기술적 독창성을 인정받은 프로젝트야. 아래의 핵심 기술 3가지를 바탕으로, 포트폴리오나 기술 명세서에 들어갈 수 있도록 매우 전문적이고 설득력 있는 한글 문구로 다듬어줘.

핵심 기술 분석 데이터
1. Medical Context-Aware Pipeline (의료 맥락 인지 파이프라인)

기술적 구현: 사고 발생 시 사용자가 말을 할 수 없는 상태(기절, 낙마 등)를 가정하여, MongoDB에서 혈액형·지병·복용약 등 개인 의료 프로필을 즉시 호출하고 이를 OpenAI LLM 컨텍스트에 주입함.

비즈니스 가치: 119 구급대원에게는 정확한 병력 데이터를 즉시 전달하고, 일반인 구조자에게는 "당뇨 환자이니 입에 음식을 넣지 마세요"와 같이 특정 환자에게 치명적일 수 있는 처치를 선제적으로 차단함.

2. High-Reliability LLM Orchestration (고신뢰성 AI 엔진 설계)

기술적 구현: 의료 정보의 할루시네이션(환각)을 방지하기 위해 표준 응급 처치 매뉴얼을 기반으로 엄격한 시스템 프롬프팅을 설계함.

데이터 구조화: 위험도 수치와 즉시 행동 지침을 구조화된 JSON으로 파싱하여 응답의 일관성을 유지하며, 딱딱한 의학 용어를 비전문가가 현장에서 즉시 실행 가능한 '행동 중심 구어체'로 변환함.

3. Zero-Latency Voice-First Interface (저지연 음성 중심 인터페이스)

기술적 구현: 응급 현장에서 시선이 환자에게 고정되어야 하는 특수성을 고려하여 Voice-First UX를 채택함. Web Speech API(브라우저)와 gTTS(백엔드)를 하이브리드로 운용하여 네트워크 지연을 최소화함.

심리적 설계: 단계별 처치 가이드와 함께 "잘하고 있습니다"와 같은 심리 안정 멘트를 병행 송출하여 구조자의 이탈을 방지하고 처치 완수율을 높임.

너에게 요청하는 작업:
위 내용들을 바탕으로, '도전 과제(Challenge) - 해결 방법(Solution) - 기술적 성과(Impact)' 구조가 명확히 드러나도록 전문적인 문구로 정리해줘.

이 프로젝트가 왜 특허 출원이 가능했는지, 기술적 독창성(의료 데이터와 AI 가이드의 실시간 결합 등)을 강조해줘.

현재는 웹 기반으로 핵심 로직을 증명(PoC)했지만, 향후 웨어러블 기기와의 확장성을 고려한 설계라는 점을 전문적으로 기술해줘."
